# maplemd

Command-line interface for [MapleMD](../..).

## Install

```bash
pnpm add -D maplemd
```

Or use directly via `npx`:

```bash
npx maple --version
```

## Commands

- `maple --version` - print the version.
- `maple dev` - start the Astro dev server in the current site.
- `maple build` - build the static site into `./dist`.
- `maple preview` - serve the built `dist/` locally.

More commands land as the surrounding packages arrive.
